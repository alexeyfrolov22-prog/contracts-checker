# Тест-кейсы: критический функционал

Подготовка: запустить `streamlit run app.py`. Дата проверки (по умолчанию 10.03.2026) и загрузка файлов — в боковой панели.
«Набор» означает: загрузить в интерфейс все файлы из папки. Наборы генерирует `python scripts/make_test_data.py` из `documents/`.
P0 блокирует сдачу, P1 важен для демо.
Каждый кейс автоматизирован в `tests/test_checker.py`, эталон лежит в `test_data/expected.json` и составлен вручную.
